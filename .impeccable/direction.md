# Review workbench

THESIS: Make each job application an evidence review, with one clear next action.
OWN-WORLD: Forest navigation, pale green-gray working canvas, white document surfaces, Manrope typography, ruled lists. No simulated materials or decorative imagery.
STORY: Import your real profile, define the search, save an opportunity, review the tailored documents against the requirements, approve, then submit.
FORM: Grounded seed 6ca5657d, assigned index 7. Single-user workbench with an opportunity list and a persistent document/evidence review context. No approved image comp; code-led session.

Mode: Operate. Existing planning interview confirms personal Windows use, CV evidence, broad discovery and explicit per-application approval. Code-first session assumption follows the user's instruction to implement; no image mockup is required to use the product.

FIRST VIEWPORT: 230px forest sidebar, light working canvas, quiet top breadcrumb, 36px heading. Main queue and search tools own two thirds; a slim profile/readiness rail owns the remainder.
